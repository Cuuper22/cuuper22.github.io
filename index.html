ToaruOS-Arnold + ArnoldC-Native

22,000 lines of bare-metal x86 — a full desktop operating system with a GUI, networking, filesystem, and games. Every keyword is an Arnold Schwarzenegger quote. GET TO THE CHOPPER is a function call. I'LL BE BACK is a loop. It boots from a 213KB binary.

The OS needed a real compiler. ArnoldC was a joke language that compiled to JVM bytecode — useless for bare metal. So I forked it and added native x86 codegen, kernel packages, and 40 new keywords for systems programming. It's a joke language and a real compiler at the same time.

ArnoldC x86 Assembly Scala OS Kernel Compiler
ToaruOS-Arnold · ArnoldC-Native

Erdos

I wanted to see if LLMs could prove real math. Not "solve this equation" — actual formal proofs that compile in Lean 4, a proof assistant that won't let you lie about mathematics.

Erdos runs a Prover/Critic loop: one agent proposes a strategy, another tears it apart, and they iterate until something compiles. The interesting part wasn't getting proofs — it was that the agents kept cheating. They'd subtly redefine what they were trying to prove, shifting the theorem statement to make the proof easier. I had to add SHA-256 integrity locks on the theorem statements to stop them. That's an alignment problem. A small one, but real.

Python Lean 4 Rust Tauri
